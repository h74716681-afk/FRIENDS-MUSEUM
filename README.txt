FRIENDS MUSEUM — playable 3D browser prototype

CONTENTS
- index.html: the game
- assets/rado/: 8 original Rado photographs (the stylized illustration from the ZIP is not shown in the photo gallery)
- assets/arsha/: 10 Arsha Sir photographs supplied separately

HOW TO PLAY
1. Upload this entire folder to a static web host such as GitHub Pages, keeping the folder structure.
2. Open the published site in Safari on iPad or in a desktop browser.
3. Choose a museum and enter its pass:
   - Rado: aa
   - Arsha Sir: Mujhe to 5 sal ka experience he
4. Walk toward a framed photo and press E / tap VIEW to see the original image and its funny caption.

CONTROLS
Desktop:
- W A S D or arrow keys: move
- Mouse: look around (click the game first to capture mouse)
- E: view a nearby photograph
- Shift: run
- Escape: close the photo view

iPad:
- Left virtual joystick: move
- Drag the right side of the screen: look around
- VIEW: open the nearest photograph
- RUN: run

NOTES
- This is a first playable prototype, not a native iOS/Android app.
- Three.js is loaded from jsDelivr CDN, so an internet connection is required.
- Password checks run in the browser and are for playful access control only; they are not secure authentication.
- The source photos are included as supplied and are not AI-generated or retouched.
